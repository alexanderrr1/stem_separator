# StemSeparator

Separa una canción en instrumentos con IA ([Demucs](https://github.com/facebookresearch/demucs))
y exporta una pista con los stems elegidos. El caso principal: **batería + bajo** para practicar.

La entrada es un link de YouTube o un archivo de audio. Corre en Docker, con GPU NVIDIA, y se
usa desde el navegador en `http://localhost:8000`.
